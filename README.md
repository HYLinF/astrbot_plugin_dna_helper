# 二重螺旋插件 - 密函委托定时推送

AstrBot 插件：定时向白名单 QQ 群推送《二重螺旋》（DNA）游戏的密函委托信息（角色 / 武器 / 魔之楔）。

推送以**游戏「委托密圈」风格图片**展示：固定 HTML 模板填入实时玩法名，由 AstrBot 官方 `astrbot-t2i-service`（HTML → 图片渲染）渲染成 PNG 发送；渲染不可用时自动回退文本推送。

## 功能



* **定时推送**：每小时 01:30 自动推送密函委托（角色 / 武器 / 魔之楔）

* **内容去重**：与上次成功推送内容一致时不推送，转每 5 分钟轮询，出现新内容再推送并恢复每小时节奏

* **图片**：只用t2i服务转换图片发送，失败退回文字

* **重点标注**：「探险 / 无尽」红色标注、「调停」蓝色标注，两种标注可在配置页分别开关

* **使用本地游戏账号获取委托密函（v2.6.0）**：群友用游戏账号绑定的**手机号 + 短信验证码**登录，插件以该账号身份**直连官方接口**拉取委托密函内容（官方优先，无绑定账号或凭据失效时自动回退第三方代理）；一个群可绑定多个账号，拉取时依次尝试，token 过期自动续期

* **凭证失效私聊提醒**：账号凭证判定失效时，自动给绑定该账号的 QQ 发**私聊**提醒（每账号只提醒一次，重新登录后重置），推送自动回退第三方代理不受影响

* 白名单群管理（添加 / 移除 / 查看）、手动测试（拉取当前信息 / 向群发测试消息）、启用 / 禁用推送开关、状态查询

| 命令                | 说明                                                  |

| `/dna_绑定状态`       | 查看当前账号自己的绑定状态与凭证状态（未绑定 / 已绑定、凭证正常或失效、是否已发失效提醒、绑定时间） |

| `/dna_添加白名单`      | 将当前群加入推送白名单（可带参数指定目标）                               |

| `/dna_启用推送`       | 启用定时推送（立即启动定时任务）                                    |
| `/dna_禁用推送`       | 禁用定时推送（立即停止定时任务与轮询）                                 |
| `/dna_帮助`         | 显示命令列表                                              |

## 配置

支持两种配置方式，修改同一份配置，面板保存后立即生效。

### 方式一：AstrBot 管理面板可视化配置（推荐）



| 字段                           | 说明                                                                                                 |
| ---------------------------- | -------------------------------------------------------------------------------------------------- |
| `enable_scheduled_push`      | 定时推送总开关                                                                                            |
| `enable_image_push`          | 图片推送开关（开启但渲染失败自动回退纯文字）                                                                             |
| `enable_highlight_explore`   | 「探险 / 无尽」红色标注                                                                                 |
| `enable_highlight_mediation` | 「调停」蓝色标志                                                                                      |
| `t2i_api_url`                | 文字生图 API 地址；留空用 AstrBot 官方远程服务，自部署可填自己的地址                                                          |
| `whitelist_targets`          | 推送目标列表。直接填群号即可（自动补全平台前缀），也兼容完整格式；也可在群内用 `/dna_添加白名单` 添加                                            |
| `last_pushed_signature`      | 最近一次成功推送的内容指纹（插件自动维护，勿手改）                                                                          |
| `dna_login_bind_host`        | 登录页绑定地址，默认 `127.0.0.1`（仅本机）；群友访问需 `0.0.0.0` 并放行端口                                                  |
| `dna_login_port`             | 登录页端口，默认 `8899`                                                                                    |
| `dna_login_public_url`       | 登录页**公网公开访问地址**（群内展示的链接，如 `http://<公网IP>:8899`）；**留空则按&#x20;**`http://<绑定地址>:<端口>`**&#x20;自动生成提示** |
| `dna_source_prefer_official` | 数据源策略：`true`= 官方直连优先（凭据失效自动回退代理）；`false`= 始终只用第三方代理                                                |
| `dna_accounts`               | 已绑定账号凭据列表（登录页登录后自动写入，请勿手工编辑）                                                                       |

### 方式二：直接编辑配置文件（可选）

插件目录 `config.json`（首次运行自动生成默认值），字段含义同上；配置读写为原子操作（临时文件 + 替换），损坏时自动回退默认配置。

> 启用可视化配置后，AstrBot 将配置存放到 
>
> `data/config/astrbot_plugin_dna_helper_config.json`
>
> 。

## 官方直连登录（v2.6.0）

> 可选能力：不用第三方代理，直接用
>
> **你自己的游戏账号**
>
> 走官方接口拉取委托密函，时效性与游戏内一致。
> **数据流**
>
> ：群友用手机号 + 验证码登录 → 官方凭据存机器人配置 → 定时推送时官方直连优先，失败自动回退第三方代理。

### 部署前提（一次性）



1. 配置页设置：`dna_login_bind_host=0.0.0.0`、`dna_login_public_url=http://<公网IP>:8899`（留空自动按绑定地址生成提示）、`dna_login_port=8899`

2. 放行端口：云服务器安全组 + 系统防火墙放行 TCP `8899`

3. 保存配置，插件自动重启登录服务

### 使用



* 群内发送 `/dna_登录` → 机器人给出登录链接（10 分钟有效）

* 群友打开链接 → 输入**游戏账号绑定的手机号** → 点「获取验证码」先弹出**安全验证**（官方强制要求）→ 通过后短信发出 → 输入验证码登录

* 凭据自动绑定到发送 `/dna_登录` 的 QQ；同一 QQ 重复登录直接覆盖

* `/dna_账号` 查看已绑定账号（手机号脱敏）；`/dna_登出` 解绑

* 无绑定账号时插件照常使用第三方代理，互不影响

### 验证码说明



* 手机号未在游戏中注册时验证码环节也会报错 —— 请确认手机号与游戏账号绑定一致

### 安全说明



* 手机号 + 验证码登录获得的凭据**权限等同账号本人**，仅用于定时查询密函，请只绑定本人账号

* 凭据保存在机器人服务器配置中（`dna_accounts`，invisible 字段），请勿外传服务器文件

* 登录页绑定 `127.0.0.1` 时仅本机可访问；开放公网后链接会话仍绑定发起人 QQ 且 10 分钟过期

## 依赖与运行环境



* AstrBot 4.x（生命周期钩子 `initialize` / `terminate`）

* 图片推送默认用 AstrBot 官方远程文字生图服务（开箱即用）；可选自部署 `astrbot-t2i-service` 容器并在 `t2i_api_url` 填入自己的地址；图片服务不可用时自动降级文本推送

* 密函数据源：官方 `dnabbs-api.yingxiong.com`（直连，需登录凭据）；无凭据时回退 `https://api.dna-builder.cn/graphql`

## 安装方法

### 第 1 步：安装插件

**方式 A：AstrBot 管理面板指令安装（推荐）**



1. 打开 AstrBot 管理面板（浏览器访问 `http://<AstrBot服务器IP>:<面板端口>`，默认端口见你的部署方式，通常为 `6185`）

2. 登录管理面板

3. 点击顶部 / 侧边栏 **「指令」**（或命令行 / 终端 Tab），在输入框执行：



```
/plugin install https://github.com/HYLinF/astrbot_plugin_dna_helper
```



1. 等待安装完成，AstrBot 会自动下载并加载插件，出现安装成功提示后，在「扩展」页面应能看到 **astrbot\_plugin\_dna\_helper**

**方式 B：手动放置插件目录**



1. 下载本仓库代码（GitHub 页面 `Code → Download ZIP`，或 `git clone https://github.com/HYLinF/astrbot_plugin_dna_helper.git`）

2. 解压后确认目录名为 `astrbot_plugin_dna_helper`（**目录名不能改**，否则插件无法识别）

3. 把整个目录放入 AstrBot 的 `data/plugins/` 目录（Docker 部署时为宿主机挂载到容器的数据目录，具体见第 3 步）

4. 在管理面板重启 AstrBot（或「扩展」页点击插件列表的刷新 / 重载）让插件生效

### 第 2 步：基础配置（推送群）



1. 管理面板 → **「扩展」**（插件列表）→ 找到 `astrbot_plugin_dna_helper` → 点击 **齿轮图标**（Extension Config）

2. 在配置表单中：

* `whitelist_targets`：填入要推送的**群号**（纯数字即可，插件自动补全平台前缀；多个群用逗号分隔，如 `111111111,222222222`）

* `enable_scheduled_push`：设为 `true`（启用定时推送）

1. 点击保存，配置立即生效

> 也可以在 QQ 群里直接发送 
>
> `/dna_添加白名单`
>
> ，插件会自动把当前群加入白名单，无需手动填群号。

以下可选

### 第 3 步：Docker 端口映射（Docker 部署 AstrBot 时**必须**）

登录页默认监听容器内 `8899` 端口，**只有容器内 / 本机可以访问，群友无法打开**。必须把端口映射到宿主机：

**方式 A：docker run**

容器启动参数中加端口映射（若容器已创建，需重建容器，数据卷挂载保持不变即可）：



```
docker run -d -p 6185:6185 -p 8899:8899 \
  -v /宿主机/数据目录:/AstrBot/data \
  --name astrbot soulter/astrbot:latest
```

**方式 B：docker compose**

在 `docker-compose.yml` 的服务 `ports` 下加一行，然后 `docker compose up -d` 重建：



```
services:
  astrbot:
    image: soulter/astrbot:latest
    ports:
      - "6185:6185"
      - "8899:8899"   # ← 登录页端口映射
    volumes:
      - ./astrbot_data:/AstrBot/data
```



**非 Docker 部署**（直接运行 Python）：无需映射，但需放行系统防火墙的 8899 端口（见第 4 步）。

### 第 4 步：云服务器安全组放行（公网访问登录页必做）

AstrBot 部署在云服务器（阿里云 / 腾讯云等）时，仅映射端口还不够，云控制台的安全组会默认拦截外部流量：



1. 登录云服务商控制台

2. 进入 **云服务器 ECS → 安全组 → 安全组规则（入方向）**

3. 添加一条入方向规则：

* 协议：`TCP`

* 端口范围：`8899`

* 授权对象：`0.0.0.0/0`（或仅放行你信任的 IP）

1. 保存生效

> 此步最容易遗漏：映射了端口但安全组未放行时，公网依旧打不开登录页。

**Windows / Linux 本机部署**：在系统防火墙入站规则中放行 8899 端口（Windows：控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP 8899）。

### 第 5 步：登录页配置（可选，启用本地账号登录时必做）



1. 管理面板 → 本插件配置页：

* `dna_login_bind_host`：`0.0.0.0`（允许群友从公网访问；默认 `127.0.0.1` 仅本机）

* `dna_login_public_url`：`http://<公网IP>:8899`（群内展示的登录链接；**留空则按绑定地址自动生成提示**）

* `dna_login_port`：`8899`（默认；若被占用可改，改后需同时放行新端口）

1. 保存配置，插件自动重启登录服务

2. 验证：浏览器直接访问 `http://<公网IP>:8899` 应能看到登录页（输入手机号的页面）

### 第 6 步：验证安装成功



1. 群内发送 `/dna_状态` → 机器人返回插件状态（开关、任务运行、版本），说明插件已正常工作

2. 群内发送 `/dna_测试信息` → 机器人拉取一次当前密函信息并推送图片到当前群，验证数据链路

3. 群内发送 `/dna_登录` → 机器人返回登录链接，群友登录绑定账号后，推送将优先走官方直连

4. 群内发送 `/dna_绑定状态` → 查看当前账号自己的绑定与凭证状态

### 常见问题



| 现象           | 原因与处理                                                                 |
| ------------ | --------------------------------------------------------------------- |
| 群内指令无响应      | 插件未加载：检查「扩展」页是否有本插件；插件目录名是否为 `astrbot_plugin_dna_helper`              |
| 公网打不开登录页     | ① Docker 未映射 8899；② 安全组未放行 8899；③ `dna_login_bind_host` 未设为 `0.0.0.0` |
| 推送是纯文字没有图片   | 图片渲染服务不可用：检查 `t2i_api_url`（留空用官方远程服务），网络可达后自动恢复出图                     |
| 登录页提示 "系统异常" | 验证码环节被拦截或手机号未注册：确认手机号与游戏账号绑定一致，重试验证码                                  |
| 重新部署后端口配置丢失  | Docker 端口映射需写在 compose/run 参数中（声明式持久化），容器重建后保留                        |
