# 二重螺旋插件 - 密函委托定时推送

AstrBot 插件：定时向白名单 QQ 群推送《二重螺旋》（DNA）游戏的密函委托信息（角色 / 武器 / 魔之楔）。

推送以**游戏「委托密圈」风格图片**展示：固定 HTML 模板填入实时玩法名，由 AstrBot 官方
`astrbot-t2i-service`（HTML → 图片渲染，端口 8999）渲染成 PNG 发送；T2I 不可用时自动回退为文本推送。

## 功能

- 每小时 :01:30 自动推送密函委托（角色 / 武器 / 魔之楔 三列横排卡片，仿游戏排版）
- **内容去重**：与上次成功推送的内容一致时不推送，转为每 5 分钟轮询，直到出现新内容再推送并恢复每小时推送
- **游戏风格图片**：做旧羊皮纸委托书风格——深色桌面背景上浮起米白信纸（横线纹理 + 做旧斑驳），右上角火漆「密」字印章，三栏墨色分类 + 玩法清单带序号，底部落款更新时间，自动裁剪底部空白
- **双路回退**：图片渲染失败自动回退文本推送，功能不丢
- 白名单群管理（添加 / 移除 / 查看）
- 手动测试：拉取当前信息（图片+附注）、向群发测试消息
- 启用 / 禁用推送开关（立即生效、配置持久化）
- 状态查询指令

## 命令

| 命令 | 说明 |
| --- | --- |
| `/dna_状态` | 查看插件状态：开关、任务运行、轮询、目标数、去重标记、版本 |
| `/dna_添加白名单` | 将当前群加入推送白名单（可带参数指定目标） |
| `/dna_移除白名单 <内容>` | 从白名单移除指定目标 |
| `/dna_查看推送群` | 列出全部白名单目标 |
| `/dna_测试推送群` | 向所有白名单目标发送一条测试消息 |
| `/dna_测试信息` | 拉取一次当前密函信息，以图片返回给当前群（不影响去重记录） |
| `/dna_启用推送` | 启用定时推送（立即启动定时任务） |
| `/dna_禁用推送` | 禁用定时推送（立即停止定时任务与轮询） |
| `/dna_帮助` | 显示命令列表 |

## 配置

插件支持**两种配置方式**：

### 方式一：AstrBot 管理面板可视化配置（推荐）

插件目录内置官方 `_conf_schema.json`，AstrBot 会自动在管理面板生成可视化配置页：

1. 打开 AstrBot 管理面板 → **扩展**（插件列表）→ 点击本插件的 **齿轮图标**（Extension Config）
2. 在表单里直接设置开关、添加/删除推送群号
3. 点击保存，AstrBot 自动写回配置并生效

配置项：

| 字段 | 说明 |
| --- | --- |
| `enable_scheduled_push` | 定时推送总开关（true 启用 / false 禁用） |
| `whitelist_targets` | 推送目标列表，格式 `<平台前缀>:GroupMessage:<群号>`。平台前缀随 AstrBot 机器人（消息源）名字自动变化，不是固定值；**推荐在群内发送 `/dna_添加白名单` 指令添加**，插件会自动带上当前机器人的前缀 |
| `last_pushed_signature` | 最近一次成功推送的内容指纹（插件自动维护，用于去重，勿手改） |

> 升级自旧版本时，插件会自动把旧配置里的白名单迁移到管理面板配置中，无需手动重填。

### 方式二：直接编辑配置文件（可选）

配置文件 `config.json`（与插件同目录，首次运行自动使用默认值）：

```json
{
  "enable_scheduled_push": true,
  "whitelist_targets": ["<平台前缀>:GroupMessage:123456789"],
  "last_pushed_signature": ""
}
```

| 字段 | 说明 |
| --- | --- |
| `enable_scheduled_push` | 定时推送总开关（true 启用 / false 禁用） |
| `whitelist_targets` | 推送目标列表，格式 `<平台前缀>:GroupMessage:<群号>`。平台前缀随 AstrBot 机器人（消息源）名字自动变化，不是固定值；**推荐直接用 `/dna_添加白名单` 指令添加**，插件会自动带上当前机器人的前缀，无需手填 |
| `last_pushed_signature` | 最近一次成功推送的内容指纹（插件自动维护，用于去重，勿手改） |

配置读写为原子操作（临时文件 + 替换），损坏时自动回退默认配置。

> 注意：启用可视化配置后（检测到 `_conf_schema.json`），AstrBot 会将配置存放到 `data/config/astrbot_plugin_dna_helper_config.json`（由管理面板维护）。两种方式修改的是同一份配置，面板保存后立即生效。

## 依赖与运行环境

- AstrBot 4.x（生命周期钩子 `initialize` / `terminate`）
- 可选：`astrbot-t2i-service` 容器（端口 8999，用于图片渲染，自带中文字体）；
  不可用时自动降级为文本推送，不影响功能
- 密函数据源：`https://api.dna-builder.cn/graphql`（`missionsIngame(server: "cn")`）

## 安装方法

在 AstrBot 管理面板中安装插件（或放置插件目录后重载）：

```
/plugin install https://github.com/HYLinF/astrbot_plugin_dna_helper
```

安装后将群号加入白名单即可开始推送。
